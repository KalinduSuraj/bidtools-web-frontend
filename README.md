# BidTools Web Frontend

A modern **Next.js + TypeScript** frontend for the **BidTools** platform.  
This project is built using **Next.js 14**, **TypeScript**, and **pnpm**, following a scalable and modular architecture.

---

##  Features
- ⚡ Next.js 14 (App Router)
- 🟦 TypeScript support
- 🎨 Tailwind CSS ready (optional)
- 📁 Clean and scalable folder structure
- 🔌 Easy integration with backend APIs
- 🚀 Fast installation & builds using pnpm

---

## Installation

### 1. Clone the repository
```bash
git clone https://github.com/KalinduSuraj/bidtools-web-frontend.git
```

### 2. Move into project directory
```bash
cd bidtools-web-frontend
```

### 3. Install dependencies
```bash
pnpm install
```

### 4. Running the project

#### Development mode

```bash
pnpm dev
```
Runs on: http://localhost:3000

#### Build for production
```bash
pnpm build
```

#### Start production
```bash
pnpm start
```
